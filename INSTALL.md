# Key2Joy Installation

## 1. Download and Extract

Download the release ZIP and extract it to a folder of your choice
(for example, `C:\Program Files\Key2Joy` or anywhere in your user folder).

## 2. Run Key2Joy

Open the extracted folder and double-click `Key2Joy.exe`.

### First launch: SmartScreen warning

Because Key2Joy is not signed with a commercial code-signing certificate,
Windows SmartScreen may display a "Windows protected your PC" dialog the
first time you run it. To continue:

1. Click **More info**.
2. Click **Run anyway**.

You only need to do this once.

## 3. (Optional) Create a Shortcut

Right-click `Key2Joy.exe` → **Send to** → **Desktop (create shortcut)**,
or pin it to your Start Menu for easier access.
